# halotukozak-com

Open-source Scala 3 / Kotlin libraries by [Bartłomiej Kozak](https://github.com/halotukozak). [Blog](https://halotukozak.com) · [LinkedIn](https://www.linkedin.com/in/halotukozak/)

## Projects

- [**alpaca**](https://github.com/halotukozak-com/alpaca) — type-safe lexer and parser library for Scala 3, with compile-time validation and a pattern-matching DSL.
- [**made**](https://github.com/halotukozak-com/made) — Scala 3 macro library extending `scala.deriving.Mirror` with annotation metadata, default values, and transparent wrappers.
- [**mcodec**](https://github.com/halotukozak-com/mcodec) — GenCodec-style serialization for Scala 3, built on Made.
- [**mrpc**](https://github.com/halotukozak-com/mrpc) — AVSystem/commons-style RPC framework for Scala 3, built on Made and mcodec.
- [**regex**](https://github.com/halotukozak-com/regex) — pure-Scala symbolic regex algebra with exact language containment checks, cross-built for JVM, Scala.js and Scala Native.
- [**commons**](https://github.com/halotukozak-com/commons) — shared Scala 3 utilities (JVM/JS/Native) used across the libraries above.
- [**sure**](https://github.com/halotukozak-com/sure) — type-safe value validation DSL for Kotlin Multiplatform.
